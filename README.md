- a brief description of your program
This program is a small computer game titled "Gravity Rush." It is a single player platformer, which sees a cyborg character jumping through sets of barrels. The player has the ability to switch their characters gravity, allowing them to ecsape obstacles easier. The game is an endless runner where the avatar continuously runs through the level without any ability to stop. 
- how the user interacts with it
The user interacts with the program by guiding the avatar through the obstacles. They can press W to jump over an obstacle, and the height of the jump is decided based on how long they hold down the button. The gravity swap mechanic is binded to the space bar, which turns the avatar upside down and allows them to run on the ceiling. 
- any known limitations or incomplete features
Only one obstacle is present, making the game feel empty or boring.
